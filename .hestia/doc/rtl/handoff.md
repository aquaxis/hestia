# rtl-conductor Downstream Handoff

**Target Conductor**: rtl-conductor
**Source**: Design Specification §4.6 (around lines 1328-1331), §3.3 (around lines 854-914)

## Overview

When rtl-conductor completes a build, it emits a `meta.handoff` event, and ai-conductor (§3) triggers the downstream workflow. Handoff artifacts are explicitly specified in the `[handoff]` section of rtl.toml.

## Handoff Targets

| Handoff Target | Target Conductor | Artifact | Description |
|---------------|-----------------|----------|-------------|
| fpga | fpga-conductor (§5) | Synthesizable RTL (`build/synth_ready.sv`, etc.) | Passed to fpga.toml `[sources]` |
| asic | asic-conductor (§6) | Synthesizable RTL (`build/asic_ready.sv`, etc.) | Passed to asic.toml RTL input |
| hal | hal-conductor (§8) | Bus definition (`build/bus_iface.rdl`) | Input for register map definition |

## Handoff Flow

```
[rtl-conductor: build completed]
       |
       | meta.handoff event emitted
       v
[ai-conductor: conductor-router]
       |
       |-- agent-cli send fpga '{"method":"fpga.build.v1.start",...}'
       |
       |-- agent-cli send asic '{"method":"asic.synthesize",...}'
       |
       +-- agent-cli send hal '{"method":"hal.parse.v1",...}'
```

## rtl.toml [handoff] Section

```toml
[handoff]
fpga = ["build/synth_ready.sv"]       # Passed to fpga-conductor [sources]
asic = ["build/asic_ready.sv"]        # Passed to asic-conductor [sources]
hal_bus_decl = "build/bus_iface.rdl"  # hal-conductor bus definition input
```

## Artifact Prerequisites

- All artifacts are generated after rtl-conductor build completion
- Synthesizable RTL must have passed Lint and simulation
- Bus definition file (RDL) is generated by rtl-conductor from bus interface declarations

## Integration with Downstream Conductors

### Integration with fpga-conductor

RTL handed off from rtl-conductor is automatically added to fpga.toml `hdl_files`. fpga-conductor uses it directly as synthesizable RTL.

### Integration with asic-conductor

RTL handed off from rtl-conductor is automatically added to asic.toml `rtl_files`. asic-conductor starts logic synthesis with Yosys.

### Integration with hal-conductor

Bus interface declarations defined by rtl-conductor (in RDL format) are taken as input by hal-conductor to generate register maps.
