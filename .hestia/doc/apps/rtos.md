# apps-conductor RTOS Support

**Target Conductor**: apps-conductor
**Source**: Design specification §9 (around lines 2281-2400)

## Supported RTOS List

| RTOS | Identifier | Language | Build Tool | Description |
|------|-----------|----------|------------|-------------|
| Zephyr | `zephyr` | C | west | Scalable RTOS led by Linux Foundation |
| FreeRTOS | `freertos` | C / C++ | CMake / Make | Real-time kernel led by AWS |
| Embassy | `embassy-rs` | Rust | cargo | async/await-based Rust embedded framework |
| Bare Metal | `bare-metal` | — | — | Bare metal execution without RTOS |

## Zephyr / west

### Features

- Scalable: supports MCU to MPU
- Multi-repository management via west meta-tool
- Hardware description via Device Tree
- Feature selection via KConfig

### Build Flow

```
west init → west update → west build -b <board> → west flash
```

### apps-conductor Integration

- Adapter: `west-zephyr`
- apps.toml: `[rtos] kernel = "zephyr"`
- west.yml can be managed and auto-generated by apps-conductor

## FreeRTOS

### Features

- Widely used RTOS led by AWS
- Basic kernel features: tasks, queues, semaphores, mutexes
- Numerous demos and port definitions

### Build Flow

```
Build via CMake / Make → generate .elf / .bin
```

### apps-conductor Integration

- Adapter: `freertos-builder`
- apps.toml: `[rtos] kernel = "freertos"`
- FreeRTOSConfig.h can be auto-generated by apps-conductor from the [memory] section

## Embassy (embassy-rs)

### Features

- Asynchronous embedded framework leveraging Rust's async/await
- Zero-cost abstraction: compile-time task dispatch
- embedded-hal compatible driver ecosystem
- Flash and debug integration via probe-rs

### Build Flow

```
cargo build --target <target> → probe-rs flash / cargo-embed
```

### apps-conductor Integration

- Adapter: `embassy-builder` / `cargo-embed`
- apps.toml: `[rtos] kernel = "embassy-rs"`
- Dependency management for Cargo.toml is supported by apps-conductor

## RTOS Selection Flow

ai-conductor (§3) proposes the optimal RTOS from the application specification:

| Condition | Recommended RTOS |
|-----------|-----------------|
| Rust language specified | Embassy |
| Multi-platform support | Zephyr |
| Lightweight, minimal footprint | FreeRTOS |
| Real-time priority | FreeRTOS / Zephyr |
| Rust async utilization | Embassy |
